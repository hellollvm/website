See you Saturday afternoon 🎉 This is the first offline meetup that CNRV, HelloGCC and HelloLLVM hold in Xi'an.

## Time and Venue

Saturday, October 21, 2023, 14:00 – 18:00

Rough schedule:

- 14:00 - 15:00 RISC-V track (organized by CNRV)
- 15:00 - 17:00 Compiler track (HelloGCC, HelloLLVM)
- 17:00 - 18:00 Lightning talks, free discussion

Talks lined up:

- Gao Fei — Zc* extensions
- Cao Gui — Implementing the OpenJDK Vector API on RISC-V
- Wu Mingchuan — A compiler plugin framework
- Wang Pu — Agile hardware verification with SystemC TLM 2.0
- Lightning talks (register on site)
